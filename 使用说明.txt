========================================
 AI抖音游戏情绪文案生成器 · 使用说明
========================================

【这是什么】
一个放在你电脑上的小窗口。你打一句玩游戏的大白话吐槽，
它帮你写成一条有梗、能直接发抖音评论区的文案。

它不帮你过关、不读游戏状态、不替你发布，只帮你把情绪变成"能发出去的话"。


【怎么打开】（现在有两种方式，随便选一种）

方式一 · 推荐（不用装任何东西，双击就用）
  打开文件夹：  绿色版-自己用
  双击里面的：  AI抖音游戏情绪文案生成器.exe

方式二 · 原来那种（需要电脑里装过 Python）
  双击这个文件夹里的：  启动文案生成器.bat

窗口出来就说明成功了。

⚠️ 「绿色版-自己用」这个文件夹里的东西要整个留着，不能只把 exe 单独
   拖出来放到别的地方 —— 那样会打不开。要挪就整个文件夹一起挪。

注意：双击 app.py 是不会开窗口的 —— 那是程序本体，别点它。

（另外还有一个文件夹叫「单文件版-发给别人」，里面是单独一个 exe 文件，
  适合发给朋友；缺点是每次打开要等 7 秒左右。你自己用建议还是用绿色版。）


【怎么用（3 步）】

第 1 步  在最上面的框里打一句吐槽
         例子：羊了个羊第二关玩了20把没过，气得我想砸手机

第 2 步  点蓝色的【生成文案】，等 2~4 秒

第 3 步  点绿色的【一键复制文案 + 话题】
         然后去抖音评论区粘贴就行

出来的东西分三块：
  ① 损友吐槽 —— 说给你听的，不用发（帮出口气）
  ② 可发文案 —— 复制这一段去发（不超过 60 字）
  ③ 话题     —— 2~3 个标签（复制按钮会把 ②③ 一起复制走）


【「换一版」怎么用】
不满意就点【换一版】，它会重新写一版，并且自动避开上一版，不会重复。

下面那个「还想怎么改？」的小框是可选的：
  - 想调就写一句，比如：再狠一点 / 短一点 / 往炫耀方向写
  - 点【生成文案】和【换一版】都认这个框
  - 留空也照样能用
  - 框里的字不会被清空，你随时能改


【遇到问题怎么办】

1. 双击了没反应？
   先确认你双击的是「启动文案生成器.bat」，不是 app.py。
   如果确认没点错还是没反应，多半是被安全软件拦了，告诉我，我换个启动方式。

2. 弹出「启动错误.txt」？
   那是程序自己写的错误记录。把那个文件发给我就行，不用自己看。

3. 提示「API Key 不对或已失效」
   点窗口右上角的【设置】，把 Key 重新粘贴一次。

4. 提示「这会儿用的人太多，被限流了」
   等几秒再点一次就好，这是免费模型的正常现象。

5. 提示「连不上服务器」
   先检查一下电脑能不能正常上网。


【想换 API Key / 换模型】
点窗口右上角【设置】，里面有两个框：
   ① API Key
   ② 模型名（默认 glm-4-flash-250414，免费）
改完点保存，下次打开自动生效。


【钱的事】
现在用的是智谱的免费模型，生成不花钱。
（模型名存在 config.json 里，改那一行就能换模型。这个文件不用管它。）


【它能做什么、不能做什么】

能做：把你的情绪写成一条有梗、像真人写的抖音评论。
不能做：不给你攻略、不读游戏进度、不看截图、
        不替你发布、不记录你的战绩、也不会骂你。
