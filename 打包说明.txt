========================================
 AI抖音游戏情绪文案生成器 · 打包说明
========================================

【这份是给谁看的】
给你自己。万一以后想重新做一个 exe（比如改了文案风格、换了模型），
照着这份抄一遍就行，一共 4 步，不用懂技术。

【前提】
这台电脑上要有 Anaconda 的 Python


【怎么做】

第 1 步  打开"命令提示符"
        按 Win 键 → 输入 cmd → 回车

第 2 步  复制下面这一整行进去，回车
        （建一个独立的打包小环境，装到 D:\pybuild，不碰你的主环境）

   D:\anaconda3\python.exe -m venv D:\pybuild

第 3 步  复制下面这一整行，回车（装打包工具，约 2 分钟）

   D:\pybuild\Scripts\python.exe -m pip install pyinstaller

第 4 步  复制下面这两行，一行一行回车（开始打包，约 30 秒）

   cd /d "D:\project\Project\AI抖音小游戏卡关助手"
   D:\pybuild\Scripts\python.exe -m PyInstaller --noconfirm --clean --onedir --windowed --name "AI抖音游戏情绪文案生成器" app.py

打完之后成品在：
   D:\project\Project\AI抖音小游戏卡关助手\dist\AI抖音游戏情绪文案生成器\

把 config.json 复制一份放进那个文件夹，就能直接用了。


【两个版本的区别（下面数字是实测的，不是估的）】

                    体积              启动到看见窗口     适合谁
  文件夹版 onedir    27 MB / 986个文件   1.2 ~ 2.3 秒      自己日常用（快）
  单文件版 onefile   11 MB / 1个文件     7.0 ~ 7.3 秒      发给别人（干净）

  上面第 4 步用的是 --onedir（文件夹版）。
  想做单文件版，把命令里的 --onedir 换成 --onefile 就行。

  为什么差这么多：单文件版每次双击都要先把 27 MB 内容解压到临时目录，
  解压完才启动，所以慢。文件夹版不用解压，所以快。


【⚠️ 发给别人之前必须先做一件事】
把 config.json 删掉！

因为 config.json 里存着你的 API Key，别人拿到就能用你的额度。
删掉之后，对方打开时会自动弹出"先填一次 API Key（免费）"的向导，
让他填自己的就行（我实测过这个向导会正常弹出来）。


【这次打包的实测结果】
  构建耗时：单文件版 27.8 秒 / 文件夹版 30.5 秒
  360 安全软件：没有拦截，exe 一直在磁盘上没被删
  Windows Defender：没有报毒记录
  功能自检：生成 / 复制 / 换一版 全部通过（真实调用 AI 接口）


【一处要提前知道的风险】
打包出来的 exe 是"没有数字签名"的程序。有些电脑（尤其装了 360 的）
第一次运行时会弹一个警告框，要点"允许/继续"。
这是所有自己打包的小程序的通病，不是你这个工具有问题。
